# How Public Media Saving Works

DownloadDash is built around publicly accessible media processing.

## Overview

Media availability depends on:
- public accessibility,
- source-platform rules,
- supported formats,
- regional access,
- temporary limits,
- creator privacy settings.

## Why This Happens

Source platforms regularly change how media is delivered and displayed publicly. This can affect quality options, download availability, and supported formats.

## What Users Should Know

- Not every link will work.
- Private content is not supported.
- Quality options depend on public formats.
- Some media becomes unavailable over time.
- Regional restrictions may affect access.

## Responsible Use Reminder

Only save or reuse media when you have permission or a legal right.
