# Google Search Console Steps

1. Open Google Search Console.
2. Add property: https://www.downloaddash.store
3. Verify ownership.
4. Go to Sitemaps.
5. Submit: sitemap.xml
6. Use URL Inspection for:
   - homepage
   - about
   - privacy
   - terms
   - guides
   - safety
7. Request indexing.
8. Wait for Google to crawl.
