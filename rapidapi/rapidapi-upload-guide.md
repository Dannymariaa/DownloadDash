# RapidAPI Upload Guide

Upload the generated OpenAPI documents in this exact order:

1. YouTube API - `youtube-openapi.json`
2. Instagram API - `instagram-openapi.json`
3. TikTok API - `tiktok-openapi.json`
4. Facebook API - `facebook-openapi.json`
5. Reddit API - `reddit-openapi.json`
6. Twitter API - `twitter-openapi.json`
7. Pinterest API - `pinterest-openapi.json`
8. Telegram API - `telegram-openapi.json`
9. Gallery API - `gallery-openapi.json`

For each listing, create a separate RapidAPI API, import the matching OpenAPI JSON file, confirm the production server URL, then save and test the documented endpoints before moving to the next listing.
