# RapidAPI Upload Guide

Upload the generated ZIP packages in this exact order:

1. YouTube API - `youtube.zip`
2. Instagram API - `instagram.zip`
3. TikTok API - `tiktok.zip`
4. Facebook API - `facebook.zip`
5. Reddit API - `reddit.zip`
6. Twitter API - `twitter.zip`
7. Pinterest API - `pinterest.zip`
8. Telegram API - `telegram.zip`
9. Gallery API - `gallery.zip`

For each listing, create a separate RapidAPI API, import the ZIP package or the matching OpenAPI JSON, confirm `https://api.downloaddash.store` as the server, upload the logo, paste the generated README content if needed, then test the documented endpoints before moving to the next listing.
